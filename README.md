# DAIMARUYU INBOUND BOARD

大丸有エリア インバウンド購買データのモニタリングボード（単一HTML・Chart.js v4）。

- 公開URL: GitHub Pages（このリポジトリの `index.html`）
- 現在のデータ: **2026年5月の実測サンプル（統計値）＋生成ダミー**（乱数シード固定 20260521）
- 認証: なし（発注者指示により省略。必要になれば AES-256-GCM 暗号化版に切替可能）
- `<meta name="robots" content="noindex,nofollow">` 設定済み

## データ差し替え手順

1. `index.html` 内の `const REAL = {...}` （実測 2026-05 サンプル）を受領データに置換
2. 月次実測が2ヶ月以上になったら、`M_AMT` 生成部の `if(ym==='2026-05')` 分岐を実測月のマップ参照に変更
3. ID代替集計（リピート率A・利用回数B・同月内間隔E・購買額F・コホートG・再訪H・施設数I・利用日数J）は各タブのグラフ定義にある固定配列を受領値に置換
4. すべてのウィジェットの「実データ/ダミー」バッジ（`b-real` / `b-dmy` / `b-mix`）を実態に合わせて更新

## 構成

- タブ1 KPI月次 / タブ2 国別 / タブ3 施設・店舗 / タブ4 買い回り / タブ5 リピート・定着 / タブ6 滞在・単価 / タブ7 AI・SNS(構想)
- 外部依存: Chart.js v4（jsDelivr）と Google Fonts（BIZ UDGothic）のみ
